# Historical materials

`browser-2023.R` and `README-2023.md` preserve the tracked files at commit
`9adfaac`. The 2011 Rnw, TeX, and PDF were present locally but ignored by the old
repository. They are retained here to distinguish the note's specification from
the later script. These files are historical evidence, not current instructions.

The script expects `luth2.rdata` in its working directory; the file now lives in
`data/raw/`. The Rnw also has an obsolete absolute Windows path. The current
`R/historical.R` reproduces both sets of models without modifying these sources.
`tabs/historical.csv` reports their coefficients, standard errors, p-values, and
sample sizes using the corrected component labels.


The original PDF displays July 31, 2011 and its creation timestamp agrees.
Callegaro's 2013 *Paradata in Web Surveys* chapter discusses Sood (2011)'s
browser-age analysis and lists this note in the bibliography. The primary-source
link and scope of the historical credit are documented in `docs/literature.md`.
Git history beginning in 2023 does not establish the date of public circulation.
